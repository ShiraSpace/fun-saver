🎯 יעד חיסכון: mockups

Sunshine Quest theme, 360px phone. Order follows the build: set the goal → goal set → menu entry → home.

1 · Setting the goal

Same overlay as עריכת חשבון: a white title and ✕ on the screen gradient, white field cards, and a PrimaryButton at the bottom. Search opens a sheet already searching for the goal name, the way WhatsApp's group-image search works. In v1 the results are emoji shown as picture tiles. Later the same sheet shows Pixabay photos.

2 · The goal, once set

Read-only: name, image, amount and progress, plus a way back. A goal can't be edited. A parent can only cancel it, from the menu (3c).
