🔁 Child mode — quick account switcher

Sunshine Quest, 360px phone, child menu as shipped on main. The switcher sits under «הכסף שלי». Tap any child to switch: the top card follows, and the device stays in child mode. To make room, the top card is a 56px row (40px face, 18px name) instead of the 84px centred avatar on main, the same size as the C rows.

How many children on the family:
A · Tiles: everyone, the current one marked
  • Faces and names only, no money. Each tile is 96px tall with a 52px face.
  • Every child is always in the same place, so a child learns "mine is the second one".
  • Wraps to a second line from 4 children and still fits on one screen with 5.
B · Big rows: the parent picker, always open
  • The parent account list, with 64px rows and no dropdown to open.
  • Shows each child's total in whole shekels, rounded down.
  • A child sees a sibling's money. With 5 children the menu scrolls, which the child-mode rules avoid.
C · Only the others: "switch to…" chosen
  • The card at the top already says who is shown, so the list holds only the children you can switch to.
  • Nothing to mark as current, and one fewer item to read.
  • Each row matches the top card: 56px high, a 40px face, a 18px name. Fits on one screen with 5 children.
  • Only brothers and sisters who are also in child view are listed. Switching to an account in parent view would hand the child the parent screen. With none, the section is not shown.
  • The order changes every time you switch.
